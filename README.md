# Financial KPI Dashboard using Power BI

## Project Overview
This project presents an interactive Financial KPI Dashboard developed using Microsoft Power BI. It helps analyze financial performance by tracking revenue, expenses, net profit, and profit margin.

## Key Performance Indicators (KPIs)
- **Total Revenue:** ₹3,876,000
- **Total Expenses:** ₹2,774,200
- **Net Profit:** ₹1,101,800
- **Profit Margin:** 28.43%

## Dashboard Visualizations
- Monthly Revenue vs. Expenses
- Profit by Category
- Revenue by Region
- KPI Cards for key financial metrics

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- CSV Dataset
- Data Visualization

## Key Learnings
- Data importing and preparation
- Creating DAX measures
- Calculating financial KPIs
- Building interactive charts and dashboard layouts
- Analyzing monthly, category-wise, and region-wise performance

## Project Files
- `Financial_KPI_Dashboard.pbix` – Power BI dashboard file
- `Financial_KPI_Dataset.csv` – Dataset used for analysis
- `Financial_KPI_Dashboard.png` – Dashboard screenshot (if uploaded)

## Dataset
This project uses a sample financial dataset created for learning and demonstration purposes. The data is synthetic and does not represent an actual company's financial records.
